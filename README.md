# 🪑 Furniture Rental Web App

A responsive web platform where vendors can list furniture for rent and customers can browse and rent available items. The frontend is fully developed with HTML, CSS, and JavaScript.

---

## 🚀 Features

- Vendor listing interface for uploading furniture items (images, descriptions)
- Customer-facing pages to browse and select furniture
- Login and signup functionality
- Password recovery form
- Image-based product display (beds, sofas, chairs, tables, etc.)
- Responsive design for desktop and mobile

---

## 🖥️ Tech Stack

- **HTML5** – Structure and layout
- **CSS3** – Styling and responsiveness
- **JavaScript** – Frontend validation and interactivity

Since this is a frontend-only project, no server or installation is required. You can run it directly in any modern web browser:

1. **Clone or download** the repository:
   ```bash
   git clone https://github.com/usman-7455/furniture-rental-app.git
   cd furniture-rental-app
2. Open index.html in your preferred browser:

3. Double-click index.html, or

4. Right-click and select "Open with" > your browser

5. Navigate through the pages:

5.1. Home (index.html)

5.2. Browse Furniture (browse-furniture.html)

5.3. Login/Signup (login.html, signup.html)

5.4. Password recovery (forget_password.html)

📝 Make sure all CSS and image files remain in the same directory as provided for everything to display correctly.
